# Mi Primera Página Web

Proyecto en desarrollo como parte de mi proceso de aprendizaje en **desarrollo web front-end**.

## 📌 Descripción
Este repositorio contiene la estructura inicial de una página web creada con **HTML y CSS**, con la intención de practicar buenas bases de maquetación, estilos y organización del código.  
El proyecto se encuentra en una **fase temprana** y será mejorado progresivamente.

## 🛠️ Tecnologías utilizadas
- HTML5  
- CSS3  
- JavaScript (estructura inicial)

## 🎯 Objetivo del proyecto
- Comprender la estructura básica de un sitio web
- Practicar estilos y organización visual
- Aplicar mejoras progresivas en diseño y funcionalidad
- Desarrollar disciplina en el uso de Git y GitHub
